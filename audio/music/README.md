# Music (final themes only)

Empty on purpose until the owner sends the real theme of each stage and boss fight with a list of which goes where
(owner, session 6: nothing sent so far is a final pick; those files are references in `audio/reference/`).

No file for a stage = no music there. Boss fights, menu and intro get their own names when the list arrives.
