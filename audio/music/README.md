# Music (final themes, owner's list, session 6)

Each file is matched to -16 LUFS with silence trimmed at both ends (so no stage plays 10 dB louder than the next).
A stage plays `audio/music/<arena.music>.ogg` on a loop; boss fights will use the boss names below.
M in the pause menu tries the other tracks on the current stage, in story order (`main.gd` `MUSIC_ORDER`).
