# Sound effects

Drop sound files here (.ogg, .wav or .mp3) with these exact names and the game plays them; a missing
file is simply silent. Every play nudges the pitch a little so repeats don't sound fake.

| File name | When it plays |
|---|---|
| `explosion` | small and medium explosions (missiles, napalm can) |
| `explosion_big` | big blasts (car wrecks, remote mine, SAT) |
| `launch_<weapon>` | a weapon is fired: `launch_fire`, `launch_homing`, `launch_power`, `launch_zoomy`, `launch_napalm`, `launch_napalm_cone`, `launch_reaper_skull`, `launch_ghost_missile` |
| `guns` | machine guns (every other shot) |
| `wall_slam` | a car slams into a wall |
| `pickup_weapon`, `pickup_health`, `pickup_turbo` | taking a pickup |
