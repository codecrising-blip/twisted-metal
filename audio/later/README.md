# Sounds for features not built yet (TM 2012, owner's round 5 upload)

Godot skips this folder (`.gdignore`). When a feature is built, move its sounds to `audio/sfx/` under a game name.
- `shield/` the shield energy move. `sweet_bot/` Sweet Tooth's Sweet Bot (transform + laugh).
- `primeval/` spike shot (fire, travel, impact, ready). `warhawk/` the Warhawk fight (shield, rotors, rams, barrage,
  tankers are Calypso's, flamethrower machines, troops). `minion/` Minion (+ lightning).
- `calypso/` blimp, engine-floor machinery (conveyor, generators), gates, elevator, jet crash, wrecking ball.
- `stages/` ambience for later stages (seagulls, docks, waves, wind, rain, giant fan, junkyard, mall, siren...).
- `engines/` general engines for later cars. `specials/` Shadow's burst and other specials.
