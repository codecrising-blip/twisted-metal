# 3D model references

Study material for modeling, never loaded by the game (our cars stay our own designs).

| File | What it is |
|---|---|
| `twisted-metal-black.zip` | `source/TMB_Vehicles.blend`: 19 TMB vehicle meshes ripped from the PS2 game (Axel, Brimstone, Crazy Eight, Darkside, Junkyard Dog, Manslaughter, Sweet Bot (`Mesh_1348.002`), Minion, Mr Grimm, Outlaw, Roadkill, Shadow, Spectre, Sweet Tooth, Tanker, Warhawk, Warthog, Yellow Jacket). 1.5-4k faces each, one UV set, **no textures** (they point at the ripper's PC). Shape and proportions only. Open with bpy: `bpy.ops.wm.open_mainfile(filepath=..., use_scripts=False)`. |
| `tmb_vehicles_sheet.jpg` | Clay renders of every mesh in the zip (3/4 view). |
| `sketchfab_axel_tm2.html` | Sketchfab embed only (no model data): "Axel from Twisted Metal 2" by Angel V Mendez, 75k faces. Not downloadable for free (store, Editorial licence). The container can't reach sketchfab.com. |
| `sketchfab_tm2_roster.html` | Sketchfab embed only: "Twisted Metal 2 All characters Hd High Detail" by the same artist, 642k faces, 16 TM2 cars. Not free (store, Standard licence). |
| `tm2_roster_textured_obj.zip` | **TM2's whole roster with textures** (OBJ + PNG, a PS1 rip from rigmodels.com, personal use): Dark Tooth, Minion, Thumper, Sweet Tooth, Shadow, Spectre, Twister, Warthog, Hammerhead, Grasshopper, Mr. Slam, Axel, Mr. Grimm, Roadkill, Outlaw 2. Texture prefixes: AX Axel, mg Grimm, rk Roadkill, ot Outlaw, sp Spectre, th Thumper, wh Warthog, hh Hammerhead, mn Minion, st Sweet Tooth. |
| `maps/` | Stage meshes with textures (OBJ + BMP rips). Named from their texture prefixes: `tm2_hong_kong` (HKONG2), `tm1_freeway` (XFWY), `tm1_rooftops` (SRoof); not identified yet: `map_burb` (BURB, maybe TM1 Cyburbia), `map_canal` (CANAL), `map_islands` (ISLANDS), `map_01` (01_). Look at them when that stage is built. |
| `low-poly-gage-ranger.zip` | A low-poly car sketch from another game (New Blood). Not TM. |
